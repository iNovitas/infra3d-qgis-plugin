# Changelog

## [1.0.1] - 31.07.2026

### Bugfixes

- Destroy the viewer, if the project is changed
- Abort network requests, that are not yet finished
- Add a debounce to not make too many network requests
- Provide information in browser, if the server is closed
- Use a random part and check if this port is occupied (and if so switch to another one)
- Load network when login with classic
- Show an error message if an error with the login appears

## [1.0.0] - 11.06.2026

### Added

- Support of infra3D NextGen
- Support of QGIS 4

### Removed

- Support of infra3D Classic
